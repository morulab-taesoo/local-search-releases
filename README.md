# 로컬 검색 (Local Search)

내 PC의 문서(한글·워드·엑셀·PPT·PDF·텍스트)를 **뜻으로** 찾는 Windows 앱의 설치 파일을 올리는 곳이에요. 문서는 이 PC 안에서만 읽고, 인터넷으로 나가지 않아요. 같은 색인을 Claude도 도구로 쓸 수 있어요.

- [Releases](https://github.com/morulab-taesoo/local-search-releases/releases)에서 `LocalSearch-Setup-<버전>.exe`를 받아 실행하고 **설치**를 누르면 돼요 (관리자 권한 필요 없음).
  - 서명되지 않은 프로그램이라 Windows가 "PC 보호" 창을 띄울 수 있어요. **추가 정보 → 실행**을 누르세요.
- 처음 켜면 설정 마법사가 모델 받기, 검색할 폴더 고르기, Claude 연결을 차례로 도와줘요.
- 설치한 앱은 여기서 새 버전을 확인해요.

## 모드 런처로 설치·업데이트

[모드 런처](https://github.com/morulab-taesoo/mod-launcher-releases)를 쓰면 로컬 검색·화면 번역 같은 morulab 프로그램을 한 창에서 설치하고 업데이트할 수 있어요. 새 버전이 나오면 런처에 **업데이트** 버튼이 떠요.
